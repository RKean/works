# works

Portfolio of works, Irfan bin Zainuddin (Senior PHP / Laravel Developer, Kuala Lumpur).

Static site: vanilla JS + Three.js (vendored, MIT). No build step. Served by GitHub Pages.
Client and system names are withheld; screenshots are blurred manual captures or local demo runs.

Home (`#explore`) is a small walkable 3D plaza: move with arrows / WASD (drag on touch), SPACE to jump,
E / ENTER to interact with the rings (works billboard, about, contact, skins). `#works`, `#index` and `#about`
are the browse views. Three.js addons (Reflector, post-processing) are vendored under `assets/vendor/addons/`.
